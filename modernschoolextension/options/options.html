ℹ️ About

Vidhyam Autofill Extension v2.0.0

Login with your school credentials, search for students or employees, and auto-fill their details on any webpage form.

How to use:

  1. Set the correct Backend URL above
  2. Generate an API key from your school dashboard (Settings → API Keys) with scopes: read:students and read:employees
  3. Enter the API key above
  4. Open the extension popup and login with your School ID and password
  5. Search for a student or employee
  6. Navigate to any webpage with a form
  7. Click "Autofill This Page" to fill in the details
