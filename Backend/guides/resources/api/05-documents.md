# Documents API

Base path: `/school/:schoolId/resources/documents`

---

## 1. Upload Document

```
POST /school/:schoolId/resources/documents/upload
POST /school/:schoolId/resources/documents/upload/student/:studentId
```

**Auth:** Required (`TenantContext`)

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `schoolId` | string | School identifier |
| `studentId` | string | (Optional) Student ID to associate the document with |

**Request Body:** JSON payload (shape delegated to `document_box` service)
```json
{
  "title": "Student Report Card",
  "fileUrl": "/uploads/documents/report-card.pdf",
  "studentId": "student-456",
  "type": "report_card",
  "description": "Q1 Report Card"
}
```

**Expected Response (200):**
```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "Student Report Card",
    "fileUrl": "/uploads/documents/report-card.pdf"
  }
}
```

**Error Response (500):**
```json
{
  "success": false,
  "message": "Error description"
}
```

**Note:**
- Returns `impl IntoResponse` (not `AppResult`), with manual error handling
- The 2nd route variant (`/upload/student/:studentId`) is registered but the handler ignores the `studentId` path parameter — it relies on the JSON body instead

**Test Cases:**
```yaml
name: "Upload document"
request:
  method: POST
  url: "/school/school-123/resources/documents/upload"
  body:
    title: "Student Report Card"
    fileUrl: "/uploads/documents/report-card.pdf"
    studentId: "student-456"
    type: "report_card"
expect:
  status: 200
  body:
    success: true
    data.id: number

name: "Upload document with studentId in path"
request:
  method: POST
  url: "/school/school-123/resources/documents/upload/student/student-456"
  body:
    title: "Student Report Card"
    fileUrl: "/uploads/documents/report-card.pdf"
    type: "report_card"
expect:
  status: 200
  body:
    success: true
```

## 2. List Documents

```
GET /school/:schoolId/resources/documents/box
```

**Auth:** Not required (no `TenantContext`)

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `schoolId` | string | School identifier |

**Query Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `student_id` | string | No | Filter documents by student ID |

**Expected Response (200):**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "Student Report Card",
      "fileUrl": "/uploads/documents/report-card.pdf",
      "downloadUrl": "https://cdn.example.com/uploads/documents/report-card.pdf?signature=...",
      "type": "report_card",
      "studentId": "student-456",
      "createdAt": "2026-06-21T10:00:00Z"
    }
  ]
}
```

**Note:** `downloadUrl` is a signed URL generated by the storage service for each document's `file_url` field.

**Error Response (500):**
```json
{
  "success": false,
  "message": "Error description"
}
```

**Test Cases:**
```yaml
name: "List all documents"
request:
  method: GET
  url: "/school/school-123/resources/documents/box"
expect:
  status: 200
  body:
    success: true
    data: array

name: "List documents filtered by student_id"
request:
  method: GET
  url: "/school/school-123/resources/documents/box?student_id=student-456"
expect:
  status: 200
  body:
    success: true
    data: array
```
