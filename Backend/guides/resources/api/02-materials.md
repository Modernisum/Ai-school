# Materials API

Base path: `/school/:schoolId/resources/materials`

---

## 1. List Materials

```
GET /school/:schoolId/resources/materials
```

**Auth:** Not required

**Query Parameters:**
| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `search` | string | No | - | Search keyword |
| `filter` | string | No | - | Filter expression |
| `page` | integer | No | `1` | Page number |
| `limit` | integer | No | `20` | Items per page |

**Expected Response (200):**
```json
{
  "success": true,
  "data": [
    {
      "materialName": "Microscope",
      "quantity": 50,
      "unitPrice": 5000.0,
      "unit": "pcs",
      "description": "Standard lab microscope",
      "attachmentPath": "/uploads/materials/microscope.jpg",
      "attachmentUrl": "https://cdn.example.com/uploads/materials/microscope.jpg?signature=...",
      "createdAt": "2026-01-01T00:00:00Z"
    }
  ],
  "total": 100,
  "page": 1,
  "limit": 20
}
```

**Note:** `attachmentUrl` is a signed URL generated by the storage service. It is only present when `attachmentPath` exists.

**Test Case:**
```yaml
name: "List materials"
request:
  method: GET
  url: "/school/school-123/resources/materials"
expect:
  status: 200
  body:
    success: true
    data: array

name: "List materials with pagination"
request:
  method: GET
  url: "/school/school-123/resources/materials?page=1&limit=5"
expect:
  status: 200
  body:
    success: true
    data: array
    page: 1
    limit: 5

name: "List materials with search"
request:
  method: GET
  url: "/school/school-123/resources/materials?search=Microscope"
expect:
  status: 200
  body:
    success: true
```

## 2. Get Single Material

**Path Parameters:**
| Parameter | Type | Description |

| `schoolId` | string | School identifier |
| `materialName` | string | Material name |

## 3. Create Material

```
POST /school/:schoolId/resources/materials
```

**Auth:** Required (`TenantContext`)

**Request Body:**
```json
{
  "materialName": "Microscope",
  "quantity": 50,
  "unitPrice": 5000.0,
  "unit": "pcs",
  "description": "Standard lab microscope",
  "attachmentPath": "/uploads/materials/microscope.jpg"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `materialName` | string | Yes | Unique material name |
| `quantity` | integer | No | Initial stock quantity |
| `unitPrice` | number | No | Price per unit |
| `unit` | string | No | Unit of measurement (e.g., "pcs", "kg") |
| `description` | string | No | Optional description |
| `attachmentPath` | string | No | Path to uploaded attachment file |

**Expected Response (200):**
```json
{
  "success": true,
  "data": {
    "materialName": "Microscope",
    "quantity": 50,
    "unitPrice": 5000.0,
    "unit": "pcs",
    "description": "Standard lab microscope"
  }
}
```

**Event Published:** `MaterialCreated`

**Test Case:**
```yaml
name: "Create material"
request:
  method: POST
  url: "/school/school-123/resources/materials"
  body:
    materialName: "Microscope"
    quantity: 50
    unitPrice: 5000.0
    unit: "pcs"
    description: "Standard lab microscope"
expect:
  status: 200
  body:
    success: true
    data.materialName: "Microscope"
```

## 8. Get Material History

```
GET /school/:schoolId/resources/materials/:materialName/history
```

**Auth:** Not required

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `schoolId` | string | School identifier |
| `materialName` | string | Material name |

**Expected Response (200):**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "type": "purchase",
      "quantity": 100,
      "previousQuantity": 50,
      "newQuantity": 150,
      "timestamp": "2026-06-01T10:00:00Z"
    },
    {
      "id": 2,
      "type": "distribution",
      "quantity": 10,
      "previousQuantity": 150,
      "newQuantity": 140,
      "timestamp": "2026-06-02T10:00:00Z"
    }
  ]
}
```

**Error Response (404):**
```json
{
  "success": false,
  "message": "Material not found"
}
```

**Note:** The endpoint first resolves the material name to an internal ID, then fetches transaction history.

**Test Cases:**
```yaml
name: "Get material history"
prerequisites:
  - Create material "Microscope"
  - Perform at least 1 buy/sell transaction
request:
  method: GET
  url: "/school/school-123/resources/materials/Microscope/history"
expect:
  status: 200
  body:
    success: true
    data: array

name: "Get history for non-existent material"
request:
  method: GET
  url: "/school/school-123/resources/materials/NonExistent/history"
expect:
  status: 404
  body:
    success: false
    message: "Material not found"
```

## 11. Bulk Import Materials

```
POST /school/:schoolId/resources/materials/bulk
```

**Auth:** Required (`TenantContext`)

**Request Body:**
```json
{
  "materials": [
    {
      "Material Name": "Microscope",
      "Quantity": 50,
      "Unit Price": 5000,
      "Unit": "pcs",
      "Description": "Standard lab microscope"
    },
    {
      "materialName": "Beaker",
      "quantity": 200,
      "unitPrice": 150,
      "unit": "pcs",
      "description": "Glass beaker 250ml"
    }
  ]
}
```

**Field Mapping (CamelCase + PascalCase Support):**
| PascalCase | CamelCase | Type | Description |
|------------|-----------|------|-------------|
| `Material Name` | `materialName` | string | Material name |
| `Quantity` | `quantity` | number | Stock quantity |
| `Unit Price` | `unitPrice` | number | Price per unit |
| `Unit` | `unit` | string | Unit of measurement (default: `"pcs"`) |
| `Description` | `description` | string | Description (default: `"Bulk imported"`) |

**Note:** The endpoint accepts both `{"materials": [...]}` and a root-level array `[...]` format.

**Expected Response (200):**
```json
{
  "success": true,
  "data": {
    "created": 2,
    "errors": []
  }
}
```

**Event Published:** `MaterialUpdated`

**Test Cases:**
```yaml
name: "Bulk import with materials array"
request:
  method: POST
  url: "/school/school-123/resources/materials/bulk"
  body:
    materials:
      - materialName: "Beaker"
        quantity: 200
        unitPrice: 150
        unit: "pcs"
      - materialName: "Test Tube"
        quantity: 500
        unitPrice: 25
        unit: "pcs"
expect:
  status: 200
  body:
    success: true

name: "Bulk import with PascalCase fields"
request:
  method: POST
  url: "/school/school-123/resources/materials/bulk"
  body:
    materials:
      - "Material Name": "Flask"
        Quantity: 100
        "Unit Price": 300
        Unit: "pcs"
        Description: "Erlenmeyer flask"
expect:
  status: 200
  body:
    success: true

name: "Bulk import empty materials"
request:
  method: POST
  url: "/school/school-123/resources/materials/bulk"
  body: {}
expect:
  status: 200
  body:
    success: false
    message: "Expected a 'materials' array"
```
